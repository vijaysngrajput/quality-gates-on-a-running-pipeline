The check cards, side by side

A check is a small test on data: it looks for rows that break a rule. A check card is one short page per table. You fill it in before you write any check. It says why each check exists. Lotus Retails has seven tables, and they are different on purpose.

    Read the cards

    Press a table name above to show or hide its card. Put two cards next to each other and look for what is the same and what is not.

    Every table is different. So every table needs its own checks. The same few checks on every table pass, and the data is still wrong. The card comes first. The check comes second.

    This page grows as the project goes on. Each card is a Markdown file in the checks/ folder. checks/build_page.py reads those files and writes them into this page and into checks/check_cards.json. Everything here is fictional: Lotus Retails and its data are invented for learning.

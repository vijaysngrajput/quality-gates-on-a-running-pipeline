Things to try

Four drills, and the Monday answer

  1. Watch the week. Press Run the next night seven times. After Monday one store waits. After Sunday five stores wait, and each has one line that says why.
  2. Drill: a file arrives twice. Reset. Choose a store and the next night, press Send the sales file twice, and run. The copies are set aside, and the store is still paid.
  3. Drill: a column is renamed. Press Rename a column for the next night, and run. The landing gate refuses the whole file. One store waits, five are published.
  4. Drill: a file is a day late. Press Send the sales file a day late, and run two nights. The first night the store waits and a ticket is sent. The second night the ticket is closed.
  5. Drill: impossible prices. Press Put impossible prices in every tenth line, and run. More than 5% of the file is bad, so all of it is set aside.
  6. Recover. After a drill press Switch off my faults, then Run this night again. The store sends a corrected file, and its number equals the answer key.
  7. The Monday answer. Run all seven nights. Fix cases 1, 3, 5 and 6. Then run this night again. Five stores turn to "yes". S04 stays "no": its Tuesday file never came.

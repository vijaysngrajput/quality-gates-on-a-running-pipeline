    5 · What you learned

    Five things

    1. How a table is made decides how it fails.A till, a person typing, a hand count, another company. So every table needs its own card.
    2. The same check is useless on one table and exact on another.A row count said nothing about sales. On six stores it is the best check there is.
    3. To find a row that is missing, first build the rows you expected.A check returns rows that exist. A missing stock count is a gap, not a zero.
    4. A perfect shape can carry a wrong meaning.Cents for dollars is a valid number in the right column. Compare with the last file, and with another table.
    5. A contract speaks at the door. A check speaks after the load.You want both. The contract says what was agreed. The check says what arrived.

    8 · What is still wrong

    Good checks that nobody runs at night

    Every table has a card, and every worry on a card has a check. Run by hand, they find every planted fault. But the nightly run does not know them. Tonight it would publish the same wrong numbers again, with five green checks.

    Still wrong

    Next: milestone 4, gates and quarantine. Every check becomes a test the pipeline runs itself. A failed check then does something: it stops the publish, sets the bad rows aside, or warns.

    Set up

    What this milestone needs

    Nothing new. Git, Python 3.12 or later, uv, and Docker, as in milestone 1. No API key, no cloud account, no AI.

    From the project folder

    uv sync                          # makes the virtual environment
docker compose up -d warehouse   # starts the warehouse

    To run the bonus week, then your checks and the contract, as plain programs:

    uv run python -m store_systems deliver --through 2026-08-30
cd src/m3_every_table_is_different
uv run python -m lotus_pipeline run --day 2026-08-30    # the nightly run; repeat for each night
uv run python -m lotus_pipeline inspect                 # every check, table by table
uv run python -m lotus_pipeline inspect --side-by-side  # the seven cards, compared
uv run python -m lotus_pipeline contract                # the suppliers' files against the contract
uv run pytest                                           # runs this milestone's tests

    When you are done: docker compose down.
